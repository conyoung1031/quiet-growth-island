# 安静成长岛 · Quiet Growth Island

> 给容易分心、情绪容易满出来的孩子，一个慢慢长大的小地方。

一款面向轻度 ADHD 儿童的成长陪伴 App 的**高保真可交互 UI 原型**。不是医疗诊断工具，不宣称治疗 ADHD；科学原则藏在结构里，不写在界面上。

## 预览方式

直接用浏览器打开 `index.html`：

```bash
open index.html
```

- **桌面**：左侧是屏幕导航栏（01–11），点击即可跳转；设备内所有按钮可点，能走完「安顿 → 动一动 → 小步 → 休息 → 收尾」完整闭环。
- **窄屏（≤520px）/ 真机**：自动进入全屏手机模式。
- **平铺长图模式**：`index.html?flat=1` —— 11 屏纵向铺开，适合一屏通览。
- **单屏无框模式**：`index.html?bare=1&screen=home` —— 用于截图。
- **评审参数**：`&noanim=1` 冻结动画；`&demo=calmdone|movedone|stepdone|restrun|cluesmid|records` 直接呈现各流程完成/进行态。
- 成长记录会写入 `localStorage`，刷新不丢；清缓存即重置。

## 页面结构（11 屏）

| # | 屏幕 | 内容要点 |
|---|------|----------|
| 01 | 启动 · 欢迎页 | 「今天，我们慢慢来。」小岛世界观插画；不出现 ADHD/治疗/训练等词 |
| 02 | 今日首页 | 主卡只推一件事（现在只做一件事）；备用入口最多 3 个且视觉更弱；学习入口不抢主位 |
| 03 | 身体状态选择 | 云团脑袋 / 弹簧腿 / 小火球 / 没电电池 / 小绿灯 —— 每张卡直连一个短行动 |
| 04 | 安顿流程 | 5-4-3-2-1 小观察（不出现 grounding）；小石头点亮 + 步骤推进 |
| 05 | 动一动 | 30 秒低刺激动作；温和进度环（只往上数、随时可停），停下也算完成 |
| 06 | 小步启动 | 只开始 2 分钟；三枚小步 chips；「走神了？」→「没关系，我们回到第一小步」，无失败态 |
| 07 | 健康休息 | 单一推荐（听海浪）+ 6 个低刺激备选（听雨声/慢故事/涂慢慢鱼/看云飘/找形状/抱抱枕），每个带一句说明；播放中显示「在播放 · ××」与潮汐进度；「休息时身体在悄悄做什么」氛围卡；休息规则：没有排行榜、没有无限下一关 |
| 08 | 休息收尾 | 收尾盒：3 次小海浪 + 喝水/伸展；无强制锁定、无惩罚 |
| 09 | 成长树 | 「今天的小事」只记录过程行为（开始了/说出来了/停了一下/试了一步/回来了/检查了一遍）；不比连续、不排名 |
| 10 | 找线索 | 四步：找一找→想一想→试一步→查一查；「再帮我一下」只给画图/类似小题/下一小步/错因提醒，绝不输出答案 |
| 11 | 家长小门 | 后台化：今日建议 / 休息时长 / 鼓励语 / 不给答案开关 / 简短观察摘要；无监控大屏。设置温和生效，不打断孩子正在进行的事 |

**本轮新增的支撑模块**

| 模块 | 位置 | 说明 |
|------|------|------|
| 节奏带（过渡预告雏形） | 首页 | 「现在 · 先安静一下 ｜ 接下来 · 休息 5 分」——今日节奏的最小实现，孩子永远知道现在与下一件 |
| 会话收尾机制 | 首页节奏带 | 一个 session 完成 3 件事后，小岛主动说「今天已经做得很够啦，去玩一会儿吧」——反成瘾设计 |
| 拒绝权出口 | 首页 | 「现在都不想做？小岛陪你待一会儿」→ 呼吸泡泡，不记录、不追问、无任何后果 |
| 家长建议 ↔ 儿童首页联动 | 首页 + 家长小门 | 家长切换今日建议，儿童首页主卡与节奏带同步（`?sug=1` 可预览） |
| 休息时长联动 | 休息页 + 家长小门 | 家长选 3/5/10 分钟，儿童端标题同步（`?rst=10` 可预览） |
| 小步图书馆 | 小步页 | 3 张可保存的小步卡，一键切换任务；chips/完成卡文案随之联动 |
| 身体充电站 | 身体页 | 「渴了/饿了/累了/想上厕所」——内感受提示，每个只给一个很短的行动 |
| 文案点读 | 首页/安顿/动一动/小步/休息 | 儿童主动点击才朗读（zh-CN，语速 0.95），照顾共现读写困难与情绪激动场景 |

**本地智能（零后台、零模型依赖）**

| 能力 | 实现 |
|------|------|
| 8 种建议池 | 安顿（小观察 / 贝壳呼吸）· 行动（动一动 / 小步）· 休息（海浪 / 慢故事）· 兜底（待一会儿 / 今天已经够啦） |
| 本地决策引擎 | 优先级：会话收尾 > 孩子刚选的身体状态 > 睡前安全线（夜间只推轻内容）> 家长预设 > 按时间。纯 if/else，首页来源标签透明展示「为什么是这个建议」 |
| 贝壳呼吸屏（第 12 屏） | 吸 4 呼 4 共 3 次，泡泡随呼吸缩放；小火球与建议池的落地页 |
| 找线索规则解析 | 输入算式（如 `8 - 3 = ?`）→ 正则抽数字与运算 → 生成找一找/想一想/画图提示/类似小题/下一小步五条线索。「不给答案」由代码强制执行，非提示词约束 |
| 隐私边界 | 全部数据存本地 localStorage，无任何网络请求；「小岛知道的一切，都只存在你的手机里」 |

QA 参数：`?body=battery`（身体状态联动）· `?hour=21`（时段）· `?decline=1`（拒绝权）· `?session=3`（会话收尾）· `?sug=0..4`（家长五挡：小岛自动/先安静一下/先动一动/先做一小步/可以休息）· `?demo=parse|breathdone`

## 使用逻辑守则（本产品的逻辑红线）

| ❌ 错误做法 | ✅ 逻辑约束 |
|---|---|
| 让孩子面对功能大厅自己选 | 每屏只有一个主行动，推荐由结构给出 |
| 完不成 = 失败 | 中断永远有出口：「没关系，回到第一小步」「停下也算完成」 |
| 记录变成监控感 | 记录可见、可由孩子亲手撤销，措辞是「小岛记得」 |
| 无限刷、越用越久 | 会话收尾机制：做完 3 件事小岛主动劝停 |
| 设置变更打断孩子 | 改动温和生效，不重置进行中的流程 |
| 孩子被迫接受建议 | 拒绝权出口，零后果 |
| 声音由 App 主动发出 | 点读只由孩子点击触发 |
| 提醒带紧迫感 | 过渡预告用「海浪要靠岸了」隐喻，绝不出现红色倒计时 |

## 设计系统

色板在 `css/styles.css` 的 `:root` 里以**设计令牌**定义，再由 `css/palette.css` 覆写为 ADHD 友好版本（只覆盖令牌名，不改任何类名，所以 JS 动态生成的 `.chip-mist` / `.ti-gold` 等结构照常工作）：

- **纸与卡**：`#F6F1E6` 燕麦暖纸（带细点阵） / `#FFFDF7` 暖白卡（暖纸底代替纯白，降低眩光）
- **墨色**：`#2F3D36` 深松绿（替代纯黑） / `#5B6B60` / `#656F65`
- **语义色**（全部降饱和 8–14%）：平静深绿 `#4C7264` · 休息雾青 `#2E6A66` · 行动陶土杏 `#E0A585` · 成长苔绿 `#86AE8D` · 暖光青铜金 `#7A5E1E` · 平静薄雾蓝 `#456B75` · 小火球褪色珊瑚 `#DDB1A4` · 沙色 `#E9E0C9`
- **字体**：标题 Noto Serif SC / Songti SC 衬线（陪伴感 + 辨识度），正文 PingFang SC / Noto Sans SC
- **插画**：全部为手写内联 SVG —— 小岛（太阳/山丘/灯塔/水线）、灯塔、年轮树、海浪、贝壳螺旋、放大镜等

### 为什么是这套色（ADHD 儿童 UI 依据）

| 原则 | 落地 |
|------|------|
| 低饱和 + 自然色系 | 鼠尾草绿 / 薄雾蓝 / 沙色 / 陶土杏；避开高饱和三原色与荧光 |
| 暖中性底色 | 燕麦暖白代替纯白，减少眩光与「屏幕感」 |
| 深绿代替纯黑 | 文字降噪但保持清晰 |
| 低对比 ≠ 看不清 | 全部文本达 WCAG AA（≥4.5:1）；原稿小字 2.7–3.0 已提到 4.6–5.1 |
| 一天中的光线 | `data-daypart`（morning/afternoon/evening/night），傍晚与夜里纸色自动变暖变暗 |

验证：H1 10.1 / 正文 5.0 / 绿按钮 4.9 / 小字 4.6–5.1，全部通过 AA。`?hour=20` 可预览傍晚色。

## 科学原则 → 结构映射（不在界面出现术语）

| 原则 | 界面体现 |
|------|----------|
| 外部结构化 | 首页「现在只做一件事」，每屏唯一主按钮 |
| 低选择负担 | 备用入口 ≤3、视觉弱于主建议；无功能大厅 |
| 短步骤 | 30 秒 / 2 分钟 / 一次一个小动作；步骤点而非倒计时 |
| 可视化温和进度 | 进度环只增不减、小石头点亮、潮汐线；无红色警示 |
| 正向强化 | 只记录过程行为；中断文案是「没关系，回到第一小步」 |
| 从身体状态进入情绪 | 云团脑袋/弹簧腿/小火球/没电电池/小绿灯 |
| 低刺激可停止休息 | 单一推荐 + 可换 + 提前收尾 + 柔和收尾盒 |
| 学习不给答案 | 线索四步 + 四类提示，规则卡明示「不会说出最终答案」 |
| 家长后台化 | 家长小门不进儿童主视觉；设置只映射为孩子看到的「下一步」 |

## 弹性触感系统（QQ 手感）

- **按压 Q 弹**：全部可点元素按下快速挤压（scale .9），松手沿弹簧曲线回弹过冲（`cubic-bezier(.34,1.56,.64,1)`），带轻微挤压拉伸（X/Y 不等比）
- **成功粒子**：流程完成、成长记录点亮、题目拆解时，从按钮喷出 10–16 颗语义色粒子（带重力下坠与旋转，0.8 秒消散）
- **水波纹**：所有主按钮在点击位置扩散白色涟漪
- **微弹跳**：数字变化弹跳、标签切换小跳、完成徽章 pop、Toast 弹簧入场、屏幕切换轻微过冲、欢迎页小岛缓慢漂浮
- **两条底线**：`prefers-reduced-motion` 与 `?noanim=1` 下全部自动关闭；动效只发生在「按压」与「完成」两个时刻，无常驻频闪，粒子只用语义色
- **魔法层（暖色系）**：全屏萤火虫缓慢漂移（7 颗暖金光点，呼吸明灭）；完成时刻升级为「大魔法」——星光喷泉（圆点+四角星混合 20 颗）+ 暖光晕扩散 + 全屏暖光闪（像阳光透进窗帘）+ 3 颗流星划过 + 暖话胶囊漂浮；小步完成时灯塔光束扫过天空；点亮小石头迸出微型火花；点亮成长记录飘起小爱心
- **名字与小岛宠物**：启动页首次进入输入名字（可跳过）；首页标题变「XX的今日岛」；每个页面空白处安放一座小岛场景——沙岛上一棵椰子树，孩子蹲在树旁，四周是海（岛身轻晃、海浪微动、孩子偶尔点头），下方名牌「XX的小岛」；点击会 Q 弹、飘爱心、说暖话；家长小门可改名；`?name=小杉` 可预览
- **小岛宠物落位（v2）**：小岛场景安放在各页面**右上角的空位**（页眉标签统一移至左侧），尺寸收紧至 92px；首页因右上角有头像章，保留在底部留白处；欢迎页（有大岛插画）与平铺模式不出现
- **小岛宠物落位（v3）**：全部 11 个页面统一落位**右上角**；首页原金色头像章由小岛场景取代
- **小岛宠物（v4）**：尺寸放大（126px）；「XX的小岛」不再用名牌，而是**直接写在沙滩上**（衬线字嵌在沙面，像刻在沙上的字）

## 儿童友好动效层（`css/fx.css`）

叠加在弹性触感系统之上，专门服务「更多动画、更适合孩子」这一条。设计底线是 **装饰区可以动，阅读区永远静止**：

| 位置 | 动画 |
|------|------|
| 启动页插画 | 背景云缓慢漂移（18s）、太阳呼吸（7s）、小岛起伏（8s）、水面闪光（5.5s）、星点眨眼（4.5s） |
| 小岛宠物 | 椰叶左右轻摆（7s）、海面明暗（9s）、偶尔亮起一颗小光点（7s） |
| 深色卡片 | 水波光斑缓慢游动（16s），像海边的反光 |
| 待一会儿 | 呼吸圆点外两圈涟漪扩散（6s） |
| 贝壳呼吸 | 外圈虚线慢转（28s）+ 背景气泡缓缓上浮（12s） |
| 完成时刻 | 在星光/流星之上增加 **叶子缓缓飘落（7 片）+ 一圈水纹** |
| 主按钮 | 首页主卡片按钮的阴影缓慢呼吸（5.5s），帮孩子锁定「下一步」 |

- 一律 4–18 秒一个循环，线性或缓入缓出；**无闪烁、无突然弹出、无多巴胺式连击**
- 临时元素（叶子 / 水纹 / 流星）统一登记在 `fxEls` 里，切页时由 `stopAll()` 清理
- 屏幕错峰入场增加 **1.4s 兜底定时器**：即使 `animationend` 被后台标签页吞掉，内容也不会卡在 `opacity:0`

## PWA 与隐私

- **可安装**：`manifest.webmanifest` + `sw.js`，支持添加到主屏、离线使用；注册仅在 http(s) 下进行，`file://` 直接打开同样可用
- **缓存策略 v4**：页面文档（`/` 与 `index.html`）改为**网络优先**，发版后用户下次打开即更新；静态资源（css/js/icons/manifest）缓存优先 + 后台刷新（stale-while-revalidate）。旧版「运行时缓存优先」会把老用户锁死在旧 CSS 上
- **隐私页**（第 13 屏）：数据只存本机、可一键导出 JSON / 清除；「边界」卡明确不是医疗工具与危急情况指引（找身边的大人 / 120 / 心理援助热线）
- 入口：欢迎页底部与家长小门底部「隐私与安全说明」
